## 2. Architecture / Plan

### Repo layout (target)
```
PROGRESS.md            <- this file (agent memory)
README.md              <- repo intro, links to guide + site
GUIDE.md               <- FULL single-file guide (generated by concatenating guide/*.md via build script)
guide/                 <- chapter source files, numbered: 00-intro.md, 01-..., etc.
research/              <- raw research notes (search findings, specs, prices, sources) — keep so later instances don't re-research
web/                   <- static site (index.html + assets); no build step required to view
  index.html
  css/style.css
  js/app.js            <- renders chapters, interactive comparison table, filters
  data/laptops.json    <- structured laptop data used by comparison table
  content/             <- chapter markdown copied/served for the web
scripts/build.sh       <- concatenates guide/*.md -> GUIDE.md, copies content to web/
.github/workflows/pages.yml <- deploy web/ to GitHub Pages
```

### Guide outline (chapters) — target ~25-40k words total
- 00 Intro: who this is for, TL;DR picks, how to read
- 01 Methodology: how picks were chosen, what "best" means, biases/disclaimers
- 02 What CS/SWE work actually demands (compilers, IDEs, containers, VMs, ML, web, mobile dev, gaming on side) → translates to hardware requirements
- 03 OS/platform deep dive: macOS vs Windows(+WSL2) vs Linux; dual boot; what your curriculum needs
- 04 Silicon deep dive: Apple M-series, Intel (Lunar Lake/Arrow Lake/Panther Lake), AMD (Strix Point/Strix Halo/Kraken/next), Qualcomm Snapdragon X, Nvidia N1X (if real by 2026); P-cores/E-cores; memory bandwidth; NPU relevance
- 05 RAM & storage: how much, unified memory, soldered vs upgradable, SSD speed
- 06 Display: size, resolution, panel tech (OLED vs IPS vs mini-LED), refresh, PWM, matte vs glossy, color, brightness for outdoor
- 07 Keyboard, trackpad, webcam, speakers, mic
- 08 Battery & efficiency, real-world runtime, charging (USB-C PD)
- 09 Ports, connectivity, docking, external monitors
- 10 Thermals, noise, sustained performance
- 11 Build quality, repairability, longevity, warranty, Linux compatibility
- 12 Discrete GPU: do you need one? (ML, game dev, gaming)
- 13 The picks: by budget tier (≤$600, $600-1000, $1000-1500, $1500-2200, $2200+) with detailed mini-reviews
- 14 The picks: by persona (frugal freshman, ML/AI-track, game dev, Linux purist, mobile dev, digital nomad, gamer-dev, desktop-replacement)
- 15 Buying strategy: student discounts, refurb, timing/sales calendar, config advice, what NOT to pay for, warranty
- 16 Setup guide: day-1 dev environment per OS, tools, dotfiles, backups
- 17 Accessories & ergonomics: monitors, keyboards, docks, bags, chargers
- 18 Common mistakes & myths
- 19 FAQ
- 20 Glossary
- 21 Sources / changelog
